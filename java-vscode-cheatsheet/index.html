☕ Java 基础

Language Server

代码导航

Definition / Implementation / References / Call Hierarchy。

右键符号 → Go to Definition 右键符号 → Go to Implementations 右键符号 → Find All References 右键符号 → Call Hierarchy

重构

使用 Java Language Server 的语义重构，不建议用纯文本替换修改 Java 符号。

Rename Extract Method Extract Variable Move Change Signature

结构与 Javadoc

Outline 查看类、字段、方法；悬停查看类型和 Javadoc。

Ctrl+Shift+OHover

多 JDK

项目可以配置多个 Java Runtime。Maven 使用的 JDK 仍需单独确认。

Ctrl+Shift+P Java: Configure Java Runtime 终端： java -version mvn -version

🌱 Spring Boot

Spring Boot Tools

启动应用

安装 Spring Boot Extension Pack 后，可以使用 Spring Boot Dashboard 管理应用。

@SpringBootApplication public class DemoApplication { public static void main(String[] args) { SpringApplication.run(DemoApplication.class, args); } }

Run Configuration → launch.json

IDEA 的启动配置可以映射到 VS Code 的 launch.json。

{ "type": "java", "name": "Spring Boot Dev", "request": "launch", "mainClass": "com.example.DemoApplication", "args": "--spring.profiles.active=dev", "env": {"DB_HOST":"localhost"} }

Spring Bean 导航

Java 类型关系可以由 Language Server 分析，但是运行时 Bean 选择仍由 Spring 容器规则决定。

@Primary @Qualifier("xxx") @Bean @Autowired

📦 Maven / Gradle

Build

Maven Lifecycle

./mvnw clean ./mvnw compile ./mvnw test ./mvnw package ./mvnw install

企业项目优先使用 Maven Wrapper，减少本机 Maven 版本差异。

多模块项目

以根目录 pom.xml 为工作区入口，让 Maven 管理模块、依赖、源码和测试路径。

project/ ├── pom.xml ├── common/ ├── service/ └── application/

🐞 Debug / Test

Java Debugger

断点调试

支持普通断点、条件断点、异常断点、Variables、Watch、Call Stack。

条件示例： user.getId() == 10001 Watch： user.getName()

JUnit

测试方法上方可直接 Run Test / Debug Test，也可以从 Test Explorer 管理测试。

@SpringBootTest class UserServiceTest { @Test void createUser() { // ... } }

🌿 Git

Source Control

日常操作

VS Code 内置 Git，GitLens 可增强历史、Blame 和提交分析。

Source Control → Changes → Stage → Commit → Push / Pull

.gitignore

target/ *.iml .idea/ # 如果团队统一维护 VS Code 配置， # 不要简单忽略整个 .vscode/

🧰 接口 / DB / Docker

Backend

REST Client

使用 .http 文件管理接口测试。

### 查询用户 GET http://localhost:8080/users/10001 ### 创建用户 POST http://localhost:8080/users Content-Type: application/json {"name":"张三","age":30}

数据库

VS Code 可通过数据库扩展连接 MySQL、PostgreSQL 等数据库。复杂数据库管理仍建议使用专业数据库工具。

Docker Compose

基础设施与 Java 应用分离管理。

docker compose up -d docker compose ps docker compose logs -f mysql

🐧 WSL2 / Dev Container

Environment

Windows + WSL2

推荐让 Java、Maven、Git、Docker CLI 主要运行在 Ubuntu 中，VS Code 通过 Remote - WSL 连接。

Windows 11 ↓ VS Code ↓ WSL2 / Ubuntu ├── JDK ├── Maven ├── Git └── Docker CLI

Dev Container

将 JDK、Maven、工具链和开发依赖定义在项目中，形成可复用的开发环境。

.devcontainer/ ├── devcontainer.json └── Dockerfile { "name": "Java Spring Boot", "image": "mcr.microsoft.com/devcontainers/java:21" }

☸️ Kubernetes / 🤖 AI Coding

Advanced

Kubernetes

结合 Kubernetes、Docker 扩展与 kubectl，可以在同一开发工作区管理 Java 微服务相关资源。

kubectl get pods kubectl logs <pod> kubectl describe pod <pod> kubectl get svc

AI Coding

适合代码生成、测试生成、代码解释、重构建议、SQL、接口实现与项目理解。生成代码后仍应执行编译、测试和代码检查。

需求 → 项目理解 → 代码修改 → Unit Test → Compile → Debug → Static Analysis → Code Review
