MODEL CONTEXT PROTOCOL

MCP 由浅入深完全教程

MCP（Model Context Protocol）是 Anthropic 于 2024 年发布的开放协议，它定义了 LLM 应用与外部工具、数据源之间的标准化通信接口。 本教程从「MCP 是什么」出发，逐步覆盖三大原语、传输层机制、Sampling / Roots 等进阶特性，直到安全加固与实战案例， 全程配以可运行的 Python 示例代码。

📌 阅读建议

如果你是第一次接触 MCP，建议按章节顺序阅读第 1—8 章；如果你已有基础，可直接跳到第 9 章（进阶特性）或第 12 章（实战案例）。每章末尾有"下一章"导航。
