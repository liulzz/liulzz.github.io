1.1 智能体解决什么问题

直接调用大模型 API，只能完成“一轮问答”：输入提示词，返回文本。但是真实业务往往需要更多——模型要查询数据库、要执行脚本、要记住三天前的对话、要在敏感操作前询问人工。把这些能力围绕同一个目标组织起来的程序，就是智能体（Agent）。

因此，智能体框架的价值不在于“让模型更聪明”，而在于提供一套经过验证的工程结构：模型调用、工具执行、状态持久化、权限控制、多会话管理。开发者只需关注业务本身。

1.2 AgentScope 2.0 是什么

AgentScope 由阿里巴巴通义实验室开源；其中 AgentScope Java 2.0 是面向 Java 开发者的生产级智能体框架，定位是“安全、高效、灵活、完整”，并且原生支持多租户与多会话管理。它的几个关键特点如下：

简单但完整
几分钟即可构建第一个智能体；同时覆盖开发、部署、调优全生命周期。
生产可用
内置权限系统、人机协同（HITL）、多租户、分布式状态存储，而不是把这些留给开发者自行实现。
模型无关
通过模型字符串（如 dashscope:qwen-plus）寻址，可切换 DashScope、OpenAI、Anthropic、Gemini、DeepSeek、Ollama 等。
原生 Java
JDK 17+，Reactor 响应式 API，提供 Spring Boot starter，与企业级技术栈无缝集成。

1.3 双层架构：ReActAgent 与 HarnessAgent

AgentScope Java 2.0 提供两个层级的智能体抽象。那么，它们如何分工？这是理解整个框架的第一把钥匙。

第一层：ReActAgent——推理与行动的循环

ReAct 是 Reasoning + Acting 的组合：模型先推理（决定该做什么），再行动（调用工具），然后根据工具结果继续推理，如此循环，直到给出最终答案。ReActAgent 把这个循环完整封装起来，开发者只需提供三样东西：

Model用哪个大模型思考
+
Toolkit能调用哪些工具
+
SysPrompt行为准则是什么
=
ReActAgent可运行的智能体

第二层：HarnessAgent——长期运行的完整智能体

但是，真实助理不只在一轮对话中工作。它需要在两次请求之间记住用户偏好、读写文件、把大任务委派给子智能体、先制定计划再执行。HarnessAgent 在 ReActAgent 的循环之上叠加了这些能力：

Harness 能力解决的问题
工作区 Workspace智能体拥有自己的“桌面”：AGENTS.md 人格、知识目录、技能与子智能体定义
AgentState会话状态持久化，进程重启后对话可以继续
记忆 Memory长期记忆（MEMORY.md），跨会话记住关键信息
上下文压缩 Compaction对话过长时自动压缩，避免超出模型窗口
子智能体 Subagent把专项任务委派给独立的上下文，主智能体保持清爽
计划模式 Plan Mode先探索、写计划、再动手执行，适合复杂任务
技能 Skill把操作流程沉淀为 SKILL.md 文档，按需分发与加载
沙箱 Sandbox让智能体安全地执行代码与命令，隔离风险

选型建议：一次性问答或单轮任务，ReActAgent 足够；需要跨会话持久、自主使用文件与工具的助理，那么直接使用 HarnessAgent。本教程第 2~7 章以核心构件为主，第 8 章起全面进入 Harness。

1.4 一次请求的生命周期

在阅读代码之前，先建立整体图景。下面是一条用户消息进入 HarnessAgent 后的完整旅程：

① 请求
用户消息到达
→
② RuntimeContext
定位 userId + sessionId，恢复状态
→
③ 记忆与上下文
注入 MEMORY.md 与工作区上下文
→
④ ReAct 循环
推理 → 工具调用 → 权限检查 → 继续
→
⑤ 状态回写
保存会话，按需触发压缩与记忆

第 ④ 步中，每次工具调用都要通过权限系统（第 6 章）；整个循环可以被中间件观测与拦截（第 7 章）。后续章节会逐一展开这些环节，因此现在不必记住全部细节。

1.5 核心概念速查

概念一句话解释
Msg / UserMessage消息对象；UserMessage、SystemMessage、AssistantMessage 是常见类型
ContentBlock消息的内容单元：文本（TextBlock）、图片（ImageBlock）、工具调用（ToolUseBlock）等
RuntimeContext每次调用的运行环境：userId、sessionId 与自定义元数据
AgentStateStore会话状态的持久化后端（本地 JSON 文件或 Redis）
AgentEvent智能体运行过程中产出的流式事件（文本增量、工具调用开始/结束等）
Toolkit工具的注册中心；工具以 @Tool 注解或 ToolBase 子类形式声明
Middleware生命周期钩子，用于审计、追踪、过滤等横切逻辑

  1. 一个“将用户输入的中文标题翻译为英文”的内部服务；
  2. 一个每天帮团队整理会议纪要、并且能记住每位成员汇报风格的助理；
  3. 一个能在代码仓库中自主修复缺陷、修改文件前需要审批的编码助手。

参考思路：第 1 个是单轮任务，ReActAgent 即可；第 2 个需要跨会话记忆与文件操作，应使用 HarnessAgent；第 3 个同样需要 HarnessAgent，并且必须配合权限系统（第 6 章）约束写操作。

AgentScope Java 2.0 是生产级智能体框架，双层架构是它的骨架：ReActAgent 负责单次推理-行动循环，HarnessAgent 负责长期运行的完整体验。下一章我们安装环境，并且用几十行 Java 代码构建第一个智能体。
