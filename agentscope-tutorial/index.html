这份教程怎么读

本教程假设你已经掌握 Java 基础语法与 Maven 的基本用法，但是不要求任何 AI 框架经验。全部章节按照“理论 → 场景 → 实践 → 练习”的固定结构组织：

  • 理论：先说明这个特性解决什么问题、它在整个框架中的位置；
  • 场景：给出一个贴近真实工作的小任务，例如“搭建一个会记住用户偏好的助理”；
  • 实践：用 Java 代码完成该场景，代码均来自官方文档并加以注释；
  • 练习：留一个动手任务，读者需要自己修改代码才能通过。

那么，为什么选择“场景驱动”？因为智能体框架的概念密度很高——工具、权限、记忆、沙箱彼此交织。如果只罗列 API，读者学完仍然不知道何时使用。因此，本教程让每个概念都在具体任务中出场，读者带着任务学习，理解会更加牢固。

AgentScope 2.0 特性全景

下表列出 AgentScope Java 2.0 的全部主要特性，并且标注了各特性在教程中的对应章节。学习过程中可以随时回到这张表检查自己的进度。

核心构件（Building Blocks）

特性说明章节
ReActAgent推理-行动（Reasoning-Acting）循环智能体：call、streamEvents、observe、interrupt、结构化输出、任务清单（enableTaskList）第 4 章
HarnessAgent长期运行智能体：在 ReActAgent 之上叠加工作区、记忆、技能、子智能体、计划模式等 Harness 能力第 8 章
消息与多模态UserMessage / SystemMessage / AssistantMessage；TextBlock、DataBlock、ImageBlock、ToolUseBlock、ToolResultBlock；Base64Source / URLSource第 3 章
事件流（AgentEvent）AgentStartEvent / AgentEndEvent、TextBlockDeltaEvent 增量、ToolCallStartEvent / ToolResultEndEvent、RequireUserConfirmEvent、SubagentExposedEvent 等流式事件第 3、4 章
Model 层ModelRegistry 字符串寻址（如 dashscope:qwen-plus）；DashScope / OpenAI / Anthropic / Gemini / DeepSeek / Ollama；GenerateOptions（温度、top_p、thinking budget）；Spring Boot starter 自动装配第 3 章
Tool 工具@Tool 注解声明、ToolBase 类式封装、Toolkit 注册、内置 TodoTools、MCP 客户端接入、tools.json 白名单第 5 章

💡版本说明

本教程基于 AgentScope Java v2.0.3（2026 年 9 月发布）。框架迭代较快，若官方文档与本教程存在出入，请以 java.agentscope.io 为准。由于 API 命名整体稳定，因此教程代码在后续维护版本中大概率仍然有效。

准备工作清单

  • JDK 17 或更高版本（官方建议）；
  • Maven 3.8+（或 Gradle，本教程统一使用 Maven）；
  • 一个模型 API Key，例如 DashScope（通义千问）的 DASHSCOPE_API_KEY；那么如果只有 OpenAI 兼容服务，也可以按第 3 章的方法切换地址与密钥；
  • 可选：Docker（第 12 章沙箱实践需要）。
🎯学完本教程你将能够
  • 解释 ReActAgent 与 HarnessAgent 的分工，并且根据业务选择正确的抽象；
  • 为智能体配置模型、工具、权限与中间件，构成一个完整的核心智能体；
  • 使用工作区、记忆、技能、子智能体，构建能长期运行、持续积累经验的助理；
  • 把智能体通过 Channel / Gateway 对外提供服务，并且部署到多租户生产环境。
