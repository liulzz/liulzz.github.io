结业综合实战：智能客服工单系统

15.1 项目目标

🏁结业项目：智能客服工单系统

把前十四章的能力装配成一个完整系统。需求如下：

  • 接入层：网页聊天（ChatUiChannel + SSE），按员工 ID 自动路由会话；
  • 知识层：客服规范写成技能（Git 仓库分发），产品知识放工作区 knowledge/；
  • 能力层：查询与创建工单两个工具（@Tool），故障图识别（多模态）；
  • 协作层：“退款专员”子智能体（声明式，expose_to_user）；复杂问题先计划后执行；
  • 安全层：退款操作必须人工确认（HITL），内部接口查询工具只读；
  • 运行层：长期记忆 + 上下文压缩（轻量模型），状态持久化（本地 JSON / 生产 Redis）；
  • 观测层：Otel 追踪中间件 + 会话日志审计。

15.2 主程序骨架

SupportDeskApplication.java —— 装配全部能力import io.agentscope.core.permission.PermissionBehavior;
import io.agentscope.core.permission.PermissionContextState;
import io.agentscope.core.permission.PermissionMode;
import io.agentscope.core.permission.PermissionRule;
import io.agentscope.core.state.JsonFileAgentStateStore;
import io.agentscope.core.tool.Toolkit;
import io.agentscope.core.tracing.OtelTracingMiddleware;
import io.agentscope.harness.agent.HarnessAgent;
import io.agentscope.harness.agent.memory.compaction.CompactionConfig;
import java.nio.file.Paths;
import java.util.List;

public class SupportDeskApplication {

    public static void main(String[] args) {
        // 1. 工具与权限（第 5、6 章）
        Toolkit toolkit = new Toolkit();
        toolkit.registerTool(new TicketTools());        // query/create 工单
        toolkit.registerTool(new RepairImageTools());   // 图片识别辅助

        PermissionContextState perms = PermissionContextState.builder()
                .mode(PermissionMode.DEFAULT)           // 写操作默认要确认
                .addDenyRule("drop_table", new PermissionRule(
                        "drop_table", null,
                        PermissionBehavior.DENY, "policy"))  // 绝对禁区
                .build();

        // 2. 智能体装配（第 2~14 章全部要素）
        HarnessAgent agent = HarnessAgent.builder()
                .name("support-desk")
                .sysPrompt("你是公司 IT 客服，负责工单受理、故障定位与升级转派。")
                .model("dashscope:qwen-plus")
                .toolkit(toolkit)
                .permissionContext(perms)
                .workspace(Paths.get(".agentscope/workspace"))
                .stateStore(new JsonFileAgentStateStore(  // 本地演示用；生产换 Redis（第 14 章）
                        Paths.get(".agentscope/sessions")))
                .compaction(compaction())                 // 压缩（第 9 章）
                .enablePlanMode(true)                     // 计划模式（第 10 章）
                .middlewares(List.of(new OtelTracingMiddleware()))  // 观测（第 7 章）
                .build();

        // 3. 接入层（第 13 章）：交给 Gateway 提供网页 SSE 服务
        ChatUiChannel chat = agent.channel(ChatUiChannel.create());
        new SupportDeskHttpServer(chat).start(8080);      // 你的 HTTP/SSE 层（示意）
    }

    private static CompactionConfig compaction() {
        return CompactionConfig.builder()
                .triggerMessages(30)
                .keepMessages(10)
                .build();   // 压缩/记忆可再指定轻量模型，见第 9 章
    }
}

15.4 验收标准

用以下六个场景自测，全部通过即为结业：

  1. 员工 A 上传故障截图，系统返回结构化工单字段（第 3 章）；
  2. 员工 B 询问“我的工单进度”，机器人调用工具且只查到 B 的数据（第 5 章）；
  3. 机器人建议退款时暂停，管理员在网页确认后流程继续（第 6、13 章）；
  4. 重启服务后，员工 A 的上下文与机器人对他的长期印象都还在（第 4、9 章）；
  5. 复杂故障被拆解为计划并且逐项完成（第 10 章）；
  6. 两家租户的知识与技能互不可见（第 14 章）。
