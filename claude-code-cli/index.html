Claude Code CLI 实战

不按功能清单讲，按你每天真正会遇到的事讲：接手陌生仓库、修一个 bug、第二天接着昨天的活、把重复流程固化、让它在 CI 里自动执行。 每章一个场景，命令可以直接复制。

读完能做到

用 claude 在终端里完成一次可验证的代码修改；用 CLAUDE.md 和技能把项目规范固定下来；用 -p 把 Claude Code 接进脚本和 CI；知道什么时候该限制权限、怎么控制成本。

适合谁

  • 已经会用命令行和 Git，想把 AI 编码工具真正接进日常工作的开发者。
  • 团队里要推广 Claude Code，需要一套可复制的配置与规范的人。
  • 想把 Claude Code 用到 CI、日志分析、批量重构里的工程师。

不适合：完全没碰过终端的人；只想看产品介绍、不打算动手的人。

章节

第 1 章 · 15 分钟

安装与第一次会话

装好、登录、让 Claude 用五分钟讲清楚一个陌生仓库，然后改一行代码。
第 2 章 · 20 分钟

让 Claude 懂你的项目

用 /init 和 CLAUDE.md 把构建命令、代码规范、目录约定固定下来。
第 3 章 · 25 分钟

改代码的完整闭环

计划模式、权限、执行测试、检查 diff：从需求到可提交的改动。
第 4 章 · 15 分钟

会话、分支与回滚

第二天接着干、开分支试另一种方案、改坏了怎么退回去。
第 5 章 · 25 分钟

命令、技能与子代理

把重复出现的流程写成 /deploy，把独立任务交给子代理。
第 6 章 · 20 分钟

Hooks 与 MCP

编辑后自动格式化、拦截危险改动；接入内部系统和第三方服务。
第 7 章 · 20 分钟

无头模式与 CI

用 claude -p、JSON 输出和预算上限，把审查与批处理接进流水线。
第 8 章 · 20 分钟

权限、成本与排错

权限规则、上下文管理、账单控制，以及出问题时先查什么。
速查

命令速查表（一页纸）：启动参数、会话命令、权限模式、项目文件、Hooks、MCP、无头模式、快捷键，适合打印或贴在显示器旁。

怎么读

  1. 按顺序读前 3 章，先把「问 → 计划 → 改 → 验证」这条闭环走通。
  2. 第 4–6 章按需看：如果你每天只用一个会话，先看第 4 章。
  3. 第 7 章开始涉及脚本和流水线，建议先在测试仓库里试。
  4. 第 8 章当手册，遇到权限、成本、上下文问题随时回来查。
版本说明

本教程依据 2026 年 11 月的官方文档编写，对应 Claude Code 2.1.x。CLI 的旗标和子命令更新较快，执行前用 claude --help 或 claude doctor 确认当前版本的行为。

约定

写法含义
$ 开头的代码块在系统终端执行
> 开头的代码块在 Claude Code 会话内输入
不带前缀的代码块文件内容或示例配置
