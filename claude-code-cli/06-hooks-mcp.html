第 6 章

Hooks 与 MCP

Hooks 管「发生动作时自动做什么」，MCP 管「Claude 能访问哪些外部系统」。两者都不改变主流程，但决定了它能不能融进你的工程体系。

场景

团队要求提交前必须格式化，且任何人不能改 .env。同时你希望 Claude 能查 Jira 需求和 Sentry 报错，而不是你手动复制粘贴。

6.1 Hook 是什么

Hook 是绑定在 Claude Code 生命周期事件上的 shell 命令。配置写在 .claude/settings.json（项目级）或 ~/.claude/settings.json（个人级）。

事件触发时机常见用途
PreToolUse工具调用之前拦截危险命令、保护文件
PostToolUse工具调用成功之后格式化、lint、记录日志
NotificationClaude 发出通知时桌面提醒、发消息
SessionStart会话开始注入环境信息、检查依赖
StopClaude 完成一次回复汇总结果、触发后续检查

6.2 编辑后自动格式化

把下面这段合并进 .claude/settings.json。文件里已有 hooks 时，把 PostToolUse 作为同级键加进去，不要覆盖整个对象。

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.file_path' | xargs npx prettier --write"
          }
        ]
      }
    ]
  }
}

matcher 决定对哪些工具生效；command 从标准输入拿到事件 JSON，用 jq 取文件路径。Prettier 不存在时这条命令会报错，所以先把依赖装好，或者改成项目已有的格式化命令。

6.3 拦截对 .env 的修改

先写脚本：

.claude/hooks/protect-files.sh
#!/usr/bin/env bash
set -euo pipefail

file_path="$(jq -r '.tool_input.file_path // empty')"

case "$file_path" in
  *.env|*/.env|*/.env.*|*secrets*)
    echo "Blocked: 不允许修改环境变量与密钥文件" >&2
    exit 2
    ;;
esac

exit 0
bash
chmod +x .claude/hooks/protect-files.sh

再注册：

.claude/settings.json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/protect-files.sh"
          }
        ]
      }
    ]
  }
}

退出码的含义：0 表示不反对，2 表示阻止本次调用，并把 stderr 作为反馈交给 Claude。其他非零退出码通常只记为错误，不阻止动作。

Hook 是强制约束，CLAUDE.md 不是

写在 CLAUDE.md 里的「不要修改 .env」只是上下文，Claude 仍可能判断错误。需要确定性拦截时，用 PreToolUse Hook 或第 8 章的权限拒绝规则。

6.4 接入 MCP 服务

MCP 让 Claude 调用外部工具。远程 HTTP 服务：

bash
claude mcp add --transport http notion https://mcp.notion.com/mcp

本地 stdio 服务：

bash
claude mcp add --env AIRTABLE_API_KEY=YOUR_KEY --transport stdio airtable \
  -- npx -y airtable-mcp-server

-- 之后的内容原样传给 MCP 服务进程，Claude Code 自己的选项必须写在 -- 之前。

查看与调试：

bash
claude mcp list
Claude Code 会话
> /mcp

6.5 团队共享 MCP 配置

把服务写进项目根目录的 .mcp.json，提交到仓库，团队成员启动时就会看到：

.mcp.json
{
  "mcpServers": {
    "sentry": {
      "type": "http",
      "url": "https://mcp.sentry.dev/mcp"
    },
    "jira": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "jira-mcp-server"],
      "env": {
        "JIRA_TOKEN": "${JIRA_TOKEN}"
      }
    }
  }
}

密钥不要写死在文件里，用环境变量展开。首次加载项目级 MCP 服务时会要求确认信任。

6.6 验证

  • 修改一个 .ts 文件后，Prettier 自动执行，文件格式变化
  • 要求 Claude 修改 .env，被 Hook 拦截并说明原因
  • claude mcp list 能看到服务，/mcp 里工具列表正常
  • 让 Claude 调用一次 MCP 工具，返回真实数据而不是占位内容

6.7 常见坑

坑后果改法
整个 hooks 对象被覆盖原有 Hook 全部失效合并键，不要替换整个对象
Hook 命令依赖当前目录换目录后找不到脚本用 $CLAUDE_PROJECT_DIR 拼绝对路径
Hook 里输出大量日志污染对话上下文只输出必要信息，调试用 --debug
无条件信任第三方 MCP 服务提示注入、数据外泄只接入可信服务，限制工具范围
