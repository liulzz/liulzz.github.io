Claude Code CLI 速查表

按 2026-11 官方文档整理，对应 Claude Code 2.1.x。$ 表示系统终端，> 表示会话内输入。

启动与会话

claude启动交互会话
claude "问题"带初始提示启动
claude -c继续当前目录最近会话
claude --resume打开会话选择器
claude -r "name"按名称或 ID 恢复
claude -n "name"给会话命名
claude -p "问题"非交互执行后退出
claude --version查看版本
claude doctor安装与设置诊断
claude update更新到最新版
claude setup-token生成 CI 用长期令牌
claude mcp list列出 MCP 服务

会话内命令

/help命令与快捷键帮助
/init生成 CLAUDE.md
/context查看上下文占用
/compact压缩历史，保留摘要
/clear开新会话，旧的仍可恢复
/rewind回滚代码与对话
/branch复制当前对话开分支
/rename重命名当前会话
/resume切换到其他会话
/model切换模型
/permissions查看与调整权限
/status模型、目录、设置来源
/usage /cost用量与会话成本
/mcp /hooks查看 MCP 与 Hook
/skills查看可用技能
/doctor会话内体检，可修复问题
/login切换账号或重新登录

权限模式

default工具首次使用时询问
acceptEdits自动接受文件编辑
plan只读探索，不改源码
auto分类器判断，常规操作不问
dontAsk需要确认的一律拒绝
bypassPermissions跳过提示，仅限隔离环境

Shift+Tab 循环切换模式。启动时用 --permission-mode plan 指定。

常用旗标

--model指定模型别名或全名
--add-dir增加可读写目录
--allowedTools免确认的工具白名单
--disallowedTools禁用工具或规则
--permission-mode启动时的权限模式
--append-system-prompt追加系统提示
--settings本次会话追加设置
--mcp-config加载指定 MCP 配置
--agents内联定义子代理
--fork-session恢复时新建会话 ID
--bare跳过配置自动发现，启动更快
--debug调试日志，可加分类过滤

无头与 CI

--output-formattext / json / stream-json
--input-formattext / stream-json
--json-schema约束结构化输出
--max-turns限制代理轮次
--max-budget-usd限制估算花费
--permission-prompts none无人值守时直接拒绝询问

取文本：... --output-format json | jq -r '.result'；取结构化结果：jq '.structured_output'。

项目文件

项目/
├─ CLAUDE.md             团队共享说明
├─ CLAUDE.local.md       个人本地说明（gitignore）
├─ .mcp.json             共享 MCP 配置
└─ .claude/
   ├─ settings.json      共享设置与权限
   ├─ settings.local.json 个人设置（不提交）
   ├─ rules/*.md         路径规则
   ├─ skills/<name>/SKILL.md
   ├─ commands/<name>.md 旧格式命令
   ├─ agents/<name>.md   子代理
   └─ hooks/*.sh         Hook 脚本

记忆加载顺序

组织系统目录 CLAUDE.md
个人~/.claude/CLAUDE.md
项目./CLAUDE.md 或 ./.claude/CLAUDE.md
本地./CLAUDE.local.md

导入写法 @docs/arch.md，最多四层。控制在 200 行内，细节放 .claude/rules/。

Hook 事件

PreToolUse工具调用前，可拦截
PostToolUse成功之后，格式化
UserPromptSubmit提交提示时，注入上下文
SessionStart会话开始
Stop完成一次回复
Notification发出通知

退出码 0 放行；2 阻止并把 stderr 交给 Claude；其他按错误处理。

MCP

claude mcp add --transport http notion \
  https://mcp.notion.com/mcp

claude mcp add --env KEY=xxx --transport stdio airtable \
  -- npx -y airtable-mcp-server

-- 之后是服务进程命令。共享配置写 .mcp.json，用 ${VAR} 读环境变量。

权限规则

{
  "permissions": {
    "allow": ["Bash(pnpm test:*)", "Read"],
    "ask":   ["Bash(git push:*)"],
    "deny":  ["Read(./.env)", "Bash(rm -rf:*)"]
  }
}

deny 优先于 allow。* 匹配任意文本；:* 等价于末尾空格加 *。

常用快捷键

Shift+Tab切换权限模式
Esc中断当前回答
Esc Esc空输入时打开回滚
Ctrl+C中断；空闲时清空输入，再按退出
Ctrl+D退出会话
Ctrl+R搜索历史命令
Ctrl+O展开工具调用详情
Ctrl+T任务清单开关
Ctrl+B把任务转入后台
Alt/Option+P切换模型

输入前缀

/命令或技能
@文件路径补全
!Shell 模式，执行命令并把输出带入会话
?空输入时显示快捷键帮助

排错顺序

  1. claude doctor：安装、设置语法、登录
  2. /status：模型、目录、设置来源
  3. /context all：CLAUDE.md 与规则是否加载
  4. claude --debug='mcp,startup'：Hook、MCP、启动
  5. 空目录复现：区分工具问题与项目配置问题

成本与上下文

/context看各项占用
/compact here 5压缩但保留最近 5 轮
/clear换任务时清空
/usage用量与计划额度
--max-budget-usd脚本运行的成本上限

省钱三件事：只传 diff、精确 @文件、一个任务一个会话。
